# Domänkatalog (Line 1)

Systemet består för närvarande av 10 specialiserade domäner som täcker allt från infrastruktur till AI-verktyg.

| ID | Namn | Beskrivning |
|:---|:---|:---|
| `server-map` | Server Map TH-1 | Infrastrukturkarta över Townhouse-nätverket. |
| `mcp-setup` | MCP Server Setup | Guider och konfiguration för MCP-installationer. |
| `azure-devops` | Azure DevOps Top 20 | Bästa praxis och verktyg för Azure DevOps. |
| `awesome-agents` | Awesome Agents Top 20 | Kuraterad lista över autonoma agenter. |
| `mcp-servers` | MCP Servers Top 20 | Populära MCP-implementationskällor. |
| `copilot-hooks` | Copilot Hooks | Integrationspunkter för GitHub Copilot. |
| `copilot-plugins` | Copilot Plugins Top 20 | Tillägg för Copilot-ekosystemet. |
| `copilot-skills` | Copilot Skills Top 20 | Specifika färdigheter och instruktionsset. |
| `copilot-instructions` | Copilot Instructions | Systeminstruktioner och prompt-bibliotek. |
| `copilot-agents` | Copilot Agents Top 20 | Agenter byggda för Copilot-miljöer. |
